Kalau maksudmu menambahkan repository GitHub ke folder/project yang sudah ada di laptop, alurnya seperti ini.

1. Buat repository di GitHub

Di GitHub:

  1. Klik + → New repository

  2. Isi nama repository, misalnya:
    Tugas-T2-Halaman-Profil-Semantik

  3. Pilih Public atau Private

  4. Jangan centang Add a README file kalau project lokalmu sudah punya file.

  5. Klik Create repository.

2. Hubungkan folder lokal ke repository

Misalnya project kamu ada di:

PowerShell
C:\.html

Buka PowerShell:

PowerShell
cd C:\.html

Cek apakah sudah menjadi Git repository:

PowerShell
git status

Kalau belum:

PowerShell
git init

Tambahkan semua file:

PowerShell
git add .

Commit:

PowerShell
git commit -m "Initial commit"

3. Hubungkan ke GitHub

Misalnya alamat repository kamu:

https://github.com/USERNAME/NAMA-REPOSITORY.git

Jalankan:

PowerShell
git remote add origin https://github.com/USERNAME/NAMA-REPOSITORY.git

Cek:

PowerShell
git remote -v

4. Upload ke GitHub

Kalau branch kamu main:

PowerShell
git branch -M main
git push -u origin main

Selesai. File yang ada di C:\.html akan masuk ke repository GitHub.

Kalau repository GitHub sudah berisi README

Kalau saat membuat repository kamu terlanjur mencentang README, biasanya push pertama bisa ditolak karena riwayat Git lokal dan GitHub berbeda.

Gunakan:

PowerShell
git pull origin main --allow-unrelated-histories

Kalau muncul conflict, selesaikan conflict-nya, lalu:

PowerShell
git add .
git commit -m "Merge local project with GitHub"
git push -u origin main
